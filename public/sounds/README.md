# Reaction sound credits

These clips are the soundboard reactions in `public/reactions.js`. Each file is a short excerpt of a **CC0 1.0** recording (public domain): trimmed, faded, and loudness-matched. The 🎉 sparkle button is synthesized in the browser and is not a recording.

This is the same CC0 set, prepared the same way, as the sibling party game. License for every file: [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/). Attribution is optional. The pages below are the source recordings.

Files are mono 128 kbps CBR MP3 so Chrome, Firefox, and Safari (including mobile Safari) can decode them with the Web Audio API.
